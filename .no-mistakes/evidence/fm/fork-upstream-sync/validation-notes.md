# Fork sync test evidence

Validated eight bounded local scenarios against the real Git, Firstmate scripts, installed Codex and quota-axi, and Chrome/Lavish. The individual CLI logs and rendered artifacts show the observable outputs. Synthetic stores and hook payloads do not prove authenticated vendor requests, real quota balances, or full agent sessions. No production fleet, remote forge, or operator account data was used.

The target contains both merge parents and all four fork-only commits. Two successive merges in a disposable repository preserved the fork file and both parent histories. Supporting regression suites exercised send, worker account selection, quota selection, capacity, stow, and URL capture.

## Test setup corrections and results

- send-guard.log: the literal retry lives in a .msg record; corrected the driver's initial JSON-only inspection. The product rejected the typo and persisted the explicit literal retry. No running recipient was used.
- hermes-bash32-hook.log: corrected the driver's state filename to the public .busy-state record. Real Bash 3.2 executed busy and idle hook payloads successfully and emitted the turn-ended marker.
- fm-worker-account-regression.log: initial run hit the intentional refusal of a secondmate home beneath the source root. Running the same target source from a disposable nested archive with fixtures outside that archive passed the complete worker-account suite (worker-account-relocated.log).
- fm-stow-guard-regression.log: Bash 3.2 command hashing made command -v jq retain the previous system path. Added hash -r to the new missing-jq fixture. The complete suite then passed (stow-guard-rerun.log). This one-line test repair is the only retained tracked change.
- fm-hermes-harness-regression.log and hermes-baseline.log: the unchanged broad Hermes suite fails on this macOS host because its PID-only assertion assumes Linux /proc. An exploratory platform condition exposed a second pre-existing mismatch with the host's framework Python basename (Python). That exploratory edit was reverted. The directly relevant empty-array/hook regression was driven successfully through real Bash 3.2. The broad Hermes suite is not claimed to pass.
- Lavish capture, session-open verification, listener arming, route resolution, snapshot lookup, CSSOM preservation, event-handler removal, desktop rendering and mobile rendering passed. Chrome resize hit its minimum native window width; viewport emulation corrected the screenshot setup. The mobile image is a mobile rendering of the desktop capture, not a --mobile capture.
- All browser sessions, the Lavish server, the process-event listener, HTTP server and test jobs were stopped or awaited. Process inspection found no remaining task children. Temporary source archives, homes, credentials, caches and fixtures were removed.

No full repository suite, linters, static analysis, push, PR, CI or pipeline-control phase was run. AGENTS.md has no How to test end to end section; validation followed the supplied isolated-lab contract and direct executable interfaces.
